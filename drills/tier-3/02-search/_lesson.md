title_en: "Search motions: / ? n N *"
title_ja: "検索モーション: / ? n N *"
concept_en: |
  /pattern<Enter>  — Search forward for pattern
  ?pattern<Enter>  — Search backward for pattern
  n                — Repeat last search (same direction)
  N                — Repeat last search (opposite direction)
  *                — Search forward for word under cursor
  #                — Search backward for word under cursor

  Search jumps go into the jump list — use Ctrl+o to go back.
concept_ja: |
  /pattern<Enter>  — pattern を前方検索
  ?pattern<Enter>  — pattern を後方検索
  n                — 直前の検索を同方向に繰り返す
  N                — 直前の検索を逆方向に繰り返す
  *                — カーソル下の単語を前方検索
  #                — カーソル下の単語を後方検索

  検索ジャンプはジャンプリストに記録される — Ctrl+o で戻れる。
