# バッファ — メモリ上のファイル

**バッファ**はファイルのメモリ内表現。5 ファイル開けばバッファも 5 つ — それを表示するウィンドウ数とは独立。バッファ操作を覚えれば、タブや分割を増やさずに多数のファイルを「アクティブ」に保てる。

## コマンド一覧

### 一覧 / 選択

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:ls` `:files`    | 全バッファ一覧                                      |
| `:buffers`        | `:ls` と同じ                                        |
| `:b {n}`          | バッファ `n` に切替（`:ls` の番号）                 |
| `:b {name}`       | `{name}` にマッチするバッファへ（部分一致可）         |
| `:bn` `:bnext`    | 次のバッファ                                        |
| `:bp` `:bprev`    | 前のバッファ                                        |
| `:bf` `:bl`       | 最初 / 最後のバッファ                                |
| `<C-^>` or `<C-6>` | 現在と代替バッファを切替                            |

### 削除 / アンロード

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:bd`             | バッファ削除（閉じる、ファイルはディスクに残る）    |
| `:bd!`            | 強制削除（変更破棄）                                 |
| `:bd {n,m,...}`   | 複数バッファ削除                                    |
| `:bw`             | wipeout（より深いアンロード — `:ls` からも消える）  |
| `:bufdo {cmd}`    | 各バッファで `{cmd}` 実行                            |
| `:%bd`            | 全バッファ削除                                      |

### `:ls` のフラグ

```
 1 %a   "foo.c"      line 1
 2 #h   "bar.c"      line 23
 3      "baz.c"      line 5
```

| フラグ | 意味                                                       |
|--------|------------------------------------------------------------|
| `%`    | 現在のバッファ                                             |
| `#`    | 代替バッファ（`<C-^>` の対象）                              |
| `a`    | active（ロード済・可視）                                   |
| `h`    | hidden（ロード済・非表示）                                 |
| `-`    | `'modifiable'` off（編集禁止）                              |
| `=`    | 読取専用                                                   |
| `+`    | 変更あり                                                   |
| `x`    | ロードエラー                                               |

## 使い分け

- **バッファ vs ウィンドウ vs タブ**: **バッファ**は内容、**ウィンドウ**はバッファの表示、**タブ**はウィンドウの集合。複数ウィンドウが同一バッファを表示可、1 バッファをウィンドウ無しで hidden 保持可
- **`:b {n}` vs `:b {name}`**: 番号は厳密だが `:ls` 確認要、名前は部分一致 + `<Tab>` 補完。曖昧でなければ名前を使う
- **`<C-^>` vs `:bn`**: `<C-^>` は**現在と直前**を切替（代替）、`:bn` は番号順。`<C-^>` が最速の「戻る」
- **`:bd` vs `:bw`**: `:bd` はアクティブから外すが再ロード可、`:bw` は完全消去。通常は `:bd`、完全に消したいなら `:bw`
- **バッファ一覧 vs argument 一覧**: バッファ一覧 = セッション中に開いた全ファイル、argument 一覧 = Vim 起動時に渡したファイル（`:args` で変更可）。重なるが別物
- **`:bufdo` vs `:argdo`**: `:bufdo` は **listed バッファのみ**巡回（help/quickfix/terminal 等の unlisted はスキップ）、`:argdo` は argument list のみ。プロジェクト全体リファクタなら明示 args + `:argdo`。両者は反復中に `'eventignore'` へ **`Syntax` イベントのみ**追加する（訪問するファイルごとに syntax highlight は付かない）

## 実例

```text
バッファ一覧:                  :ls
名前で切替:                    :b foo<Tab>     →  最初のマッチ
代替ファイル切替:               <C-^>
現バッファを閉じる:             :bd
全保存:                         :wa
全バッファで置換:               :bufdo %s/foo/bar/g | update
各バッファでマクロ実行:         :bufdo normal! @a
```

## Web 環境について

Web Vim エミュレーションは通常**バッファ複数を持たない** — 単一エディタのみ。本記事は実 Vim/Neovim 用。

## 落とし穴

- `:bd` は**ディスクからファイルを消さない** — メモリ上のバッファのみ。ファイル削除は `:!rm %` を先に
- バッファの最後のウィンドウを閉じると `'hidden'` 有効なら hidden、無効なら wipe。`:set hidden` でバッファを残すのが普通
- `:bn` は **listed バッファのみ**を巡回。unlisted（help、quickfix、terminal 出力等）は常にスキップ（`:bn` の `!` は「unlisted も含める」ではなく**修正バッファを abandon** する用途）。unlisted も含めて確認したいなら `:ls!`、特定のバッファに直接行くなら `:b {n}` で番号指定
- 未保存変更で別バッファに切替は `'hidden'` 無効だと拒否される。Vim はデフォルト無効、**Neovim はデフォルト有効**なので Neovim ユーザはこの落とし穴に当たりにくい
- `:ls` の番号は安定しない — 列挙順。`:bd 3` 後も既存番号は維持、新規は高い番号
