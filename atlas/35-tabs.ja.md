# タブ — 別ワークスペース

Vim の**タブページ**は独自のウィンドウレイアウトを持つ。**タブはファイル多重化機構ではない** — ワークスペースである。タブ 1 つにファイル 1 つを充てているなら、バッファの使い方が間違っている。

## コマンド一覧

### 作成

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:tabnew [{file}]` | 新タブ作成（オプションでファイル指定）             |
| `:tabe {file}`    | `:tabedit` と同じ、ファイルを新タブで開く            |
| `:tab split`      | 現バッファを新タブで開く（元ウィンドウは残る — `:tab {cmd}` でウィンドウを開く `{cmd}` を新タブ側で開かせる） |
| `:tab help`       | help を新タブで開く                                  |

### 移動

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `gt`              | 次のタブ                                            |
| `gT`              | 前のタブ                                            |
| `{n}gt`           | `n` 番目のタブへ（**1-indexed**）                   |
| `:tabnext` `:tabprev` | `gt`/`gT` と同じ                                |
| `:tabfirst` `:tablast` | 最初 / 最後のタブ                              |
| `:tabmove [{n}]`  | 現タブを移動。**mixed semantics**: `:tabmove 0` で先頭（special case）、`:tabmove N`（N≥1）で位置 N の**後ろ**（1-indexed）、`:tabmove $` で末尾、`:tabmove +1` `:tabmove -1` で相対、引数なしで末尾 |

### 閉じる

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:tabc` `:tabclose` | 現タブを閉じる                                    |
| `:tabo` `:tabonly` | 他のタブをすべて閉じる                             |
| `:qa`             | 全終了                                              |

### 全タブで操作

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:tabdo {cmd}`    | 各タブで `{cmd}` 実行                                |

## 使い分け

- **タブ vs バッファ vs ウィンドウ**: タブ = ワークスペース（別タスクのレイアウト/ファイル群）、ウィンドウ = バッファの表示、バッファ = ファイル内容。ファイル切替には buffer (`:b`) か window、タブは**コンテキスト**切替（プロジェクト領域、ドキュメント閲覧 vs コーディング）用
- **`gt` vs `:bn`**: `gt` はタブ巡回、`:bn` はバッファ巡回。混同しない — タブは粗い粒度
- **`:tabe file` vs `:e file`**: `:tabe` は新タブで開く、`:e` は現バッファを置換。新ファイルが独自ワークスペースに値するなら `:tabe`
- **`:tab split` vs `:tabnew`**: `:tabnew` は空の新タブを開く。`:tab split` は**現バッファを新タブで開く**（元ウィンドウは残る — `:split` の `:tab` modifier 版、別タブページ側で `:split` する形）。同じファイルを別ワークスペースで見たい時に便利
- **ブラウザ風タブ vs Vim タブ**: 多くのエディタはタブをファイル一覧として使う。Vim は違う。VSCode/Sublime からタブ＝ファイルの期待で来たなら、**バッファモデルを学ぶ方がよい** — 強力

## 実例

```text
ファイルを新タブで:             :tabe other.c
起動時にタブで開く:             vim -p file1 file2 file3
タブ巡回:                       gt → gt → gt
3 番目のタブへ:                 3gt
現タブを末尾に移動:             :tabmove
現タブを閉じる:                 :tabc
全タブでマクロ実行:             :tabdo normal! @a
help をタブで:                  :tab help motion.txt
```

## タブライン

上部のタブラインはタブ番号と短い名前を表示。`'tabline'` `'guitablabel'` で設定。デフォルトは各タブの現バッファの basename。

## Web 環境について

Web Vim エミュレーションは通常タブページを持たない。

## 落とし穴

- タブはメモリ削減やバッファ管理の単純化にはならない。状態が 1 層増えるだけ
- `:tabc` は**現タブの全ウィンドウ**を閉じてタブごと破棄する。`'hidden'` が無効で未保存バッファがあれば拒否される — 先に保存するか `:tabc!`
- タブ切替はウィンドウローカル状態（`'cursorline'`、分割）を保持 — 便利だが驚かれる: 各タブは独自構成
- `:tabdo` は**各タブで 1 回**（そのタブの現ウィンドウ）。各タブの各ウィンドウなら `:windo` と組合せ
- 多くのプラグインはタブを無視する — 単一タブ前提。依存前にテスト
- **index 体系が混在**: `{n}gt` は 1-indexed（`3gt` で 3 番目）。`:tabmove` は癖あり — `:tabmove 0` だけ special case で「先頭」、`:tabmove N`（N≥1）は「位置 N の**後ろ**」（`:tabmove 2` で 2 番目の後ろ = 3 番目に着地）。罠を避けるなら `:tabmove $` / `+1` / `-1` を使う
