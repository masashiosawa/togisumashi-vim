# レジスタ — Vim のクリップボード体系

Vim には **10 種類・約 50 個**のレジスタがあり、テキストとマクロを格納する。アーキテクチャを知っているかで、無名レジスタを呪うか武器化するかが変わる。

## レジスタの種類

| レジスタ     | RW | 用途                                                              |
|--------------|----|-------------------------------------------------------------------|
| `""`         | RW | **無名** — 最後のヤンク/削除（`p` `y` `d` のデフォルト）          |
| `"0`         | RW | **ヤンク** — 無修飾 `y`（`yy`、`yw` 等）で更新。名前付きヤンク（`"ay`）では `"a` のみに書き込まれ `"0` には入らない。`d`/`c`/`x` では更新されない |
| `"1`–`"9`    | RW | **削除/変更履歴** — 複数行にまたがる/改行を含む削除/変更、**または** `%`、`(`、`)`、`` ` ``、`/`、`?`、`n`、`N`、`{`、`}` motion を伴う削除（サイズ問わず） |
| `"-`         | RW | **小削除** — 行内に収まる削除/変更（改行を含まない）でレジスタ未指定時 |
| `"a`–`"z`    | RW | **名前付き** — 明示的・セッション内で永続                          |
| `"A`–`"Z`    | RW | **追記** — 大文字で対応小文字レジスタに追記                       |
| `"_`         | RW | **ブラックホール** — 破棄（保存しない）                            |
| `"+`         | RW | システムクリップボード（X11/Wayland では CLIPBOARD 選択、macOS/Windows では pasteboard）。Vim は `+clipboard` ビルド、Neovim は provider 必要 |
| `"*`         | RW | X11 PRIMARY 選択（中ボタンペースト）、macOS/Windows では `"+` と同等 |
| `"~`         | RO | 直前のドロップ（drag-and-drop で Vim に入ったテキスト）— 読出専用。GTK GUI Vim 限定（Neovim では利用不可） |
| `"/`         | RW | 最後の検索パターン（`:let @/` で書込可能）                         |
| `"#`         | RW | **代替**バッファ名（alternate-buffer レジスタ）                    |
| `":`         | RO | 最後の ex コマンド（読出専用 — `<C-r>:` で参照）                   |
| `".`         | RO | 最後に挿入したテキスト（読出専用）                                |
| `"%`         | RO | 現在のファイル名（読出専用）                                      |
| `"=`         | RW | **式レジスタ** — 読み出し時に評価。`:let @= = 'expr'` で書込可     |

## 使い方

| 文法                | 意味                                                |
|---------------------|-----------------------------------------------------|
| `"{r}y`             | レジスタ `{r}` にヤンク                              |
| `"{r}d`             | レジスタ `{r}` に削除                                |
| `"{r}p`             | レジスタ `{r}` からペースト                           |
| `:reg`              | 全レジスタ表示（`:reg a b c` で個別）                |
| `:let @{r}='...'`   | プログラム的にレジスタ設定                          |
| `<C-r>{r}`          | Insert / コマンドラインでペースト                    |
| `<C-r>={expr}<CR>`  | 式の評価結果を挿入                                  |

## 使い分け

- **`""` vs `"0`**: `""` は全ての**ヤンクと削除**（`y` `d` `c` `s` `x`）で上書き。`"0` は**無修飾のヤンクのみ**（`yy`、`yiw`、`y$` 等）で更新。名前付きヤンク（`"ay`）では `"a` だけ書き込まれ `"0` は触らない。削除では決して更新されない。ヤンク後に削除して `p` すると削除内容、`"0p` ならヤンク内容が出る
- **`"1`–`"9` vs `"-`**: 複数行にまたがる/改行を含む削除/変更、**または** `%`、`(`、`)`、`` ` ``、`/`、`?`、`n`、`N`、`{`、`}` motion を伴う削除はサイズに関わらず `"1` に入る（新規ごとに `"1`→`"2` シフト）。行内に収まる削除/変更（改行なし）は `"-` に入る。`"ad` のように明示指定すれば `"a` に書き込まれるが、`"1`/`"-` の履歴コピーは同じルールで作られる
- **`"0` vs `"+`/`"*`**: `"0` は Vim 内部。`"+` は OS クリップボードと連動。ブラウザ等と共有するなら `"+y`/`"+p`（または `:set clipboard=unnamedplus` で `""` を自動的にシステムクリップへ）
- **`"+` vs `"*`**: 全 OS で `"+` がシステムクリップボード。X11 では `"*` が PRIMARY 選択（中ボタンペースト）と別物だが、macOS/Windows では `"*` も `"+` と同じシステムクリップを指す
- **`"a` vs `"A`**: 小文字は**上書き**、大文字は**追記**。スニペット集めるなら `"Ay` で蓄積
- **`"_d` vs `d`**: `"_d` はブラックホール削除 — `""` の内容を保持。ヤンクした内容で置換したい時に必須
- **`"=`（式） vs `<C-r>=`**: `"=` は Normal モードで式結果をペースト（`"=1+1<CR>p` で `2` ペースト）、`<C-r>=` は Insert / コマンドラインでインライン挿入

## 実例

```text
全レジスタ表示:                       :reg
特定レジスタ:                         :reg a 0 "

名前付きにヤンクして後でペースト:       "ayy  ...  "ap

無名を汚さず削除:                     "_d （削除のみ）
                                      "0p （最後のヤンクをペースト）

レジスタ a に追記:                    "Ayy   （`"Ay` を重ねて蓄積）

システムクリップから貼る:              "+p
システムクリップへヤンク:              "+yy

ファイル名を ex に挿入:                :e <C-r>%

数式結果を挿入:                       <C-r>=10*10<CR>

最後の検索を呼出:                     "/p  （検索パターンをテキストとして配置）
```

## 落とし穴

- 無名レジスタは**破壊的** — 全削除で上書きされる。習慣として保存したくない削除は `"_d`、最後のヤンクが欲しいなら `"0p`
- `"+y` は `+clipboard` 付きビルドが必要。`:echo has('clipboard')` で確認。軽量ビルドには無いことも
- `:reg a` は内容表示、`"ay` は書込。コロンとクォートを混同しない
- `"A`（追記）は**末尾**にのみ追加。先頭追加には `:let @a = '...' . @a` が必要
- 読出専用レジスタ: `":` `".` `"%` `"~`。ペースト元としては使えるが `y`/`d` で書き込めない。`"/` は `:let @/` で書込可（検索ごとに更新）、`"#` も書込可（代替バッファ、RO ではない）
- `"+y` は Vim では `+clipboard` ビルド、Neovim では provider（macOS は `pbcopy`、Linux は `wl-copy`/`xclip`）が必要。`:echo has('clipboard')` または Neovim では `:checkhealth` で確認
- Insert の `<C-r>"` は無名レジスタをペーストするがカーソルはそのまま — Normal の `p`（カーソルがペースト末尾に移動）と違う
