# Insert モードのショートカット

編集時間の半分は Insert にいる。Insert を**出ずに**ミス修正・レジスタペースト・1 回限りの Normal コマンドを実行する技。

## コマンド一覧

### モード脱出

| Key      | 動作                                                |
|----------|-----------------------------------------------------|
| `<Esc>`  | Normal モードへ                                     |
| `<C-c>`  | Normal へ（InsertLeave autocmd をスキップ）         |
| `<C-[>`  | `<Esc>` と同じ（同じバイト）                        |

### 後方削除

| Key      | 動作                                                |
|----------|-----------------------------------------------------|
| `<BS>`   | 直前の文字を削除。既存テキストや行をまたぐかどうかは `'backspace'` 依存（`<C-w>` / `<C-u>` と同じ制約） |
| `<C-w>`  | カーソル前の**単語**を削除。既存テキストや行をまたぐかどうかは `'backspace'` 依存 |
| `<C-u>`  | この Insert セッションで入力した文字を行頭まで削除（行全体ではない。`'backspace'` の許可なしには既存テキストは消さない） |
| `<C-h>`  | `<BS>` と同じ                                       |

### 1 回限りの Normal コマンド

| Key          | 動作                                                            |
|--------------|-----------------------------------------------------------------|
| `<C-o>{cmd}` | Normal コマンドを 1 回実行して Insert に戻る                    |

### レジスタからペースト

| Key             | 動作                                                       |
|-----------------|------------------------------------------------------------|
| `<C-r>{r}`      | レジスタ `{r}` を「入力されたように」挿入（`<BS>` 等の特殊キーは実行される）。mapping と略語は**適用されない**。`'textwidth'` `'formatoptions'`・自動インデントは受ける |
| `<C-r><C-r>{r}` | `<C-r>{r}` と同じだが**リテラル** — レジスタ内の制御文字は実行されずデータとして挿入。`'textwidth'` `'formatoptions'`・自動インデントは**依然適用される** |
| `<C-r><C-o>{r}` | リテラル + **自動インデント抑止**。linewise レジスタは現在行の**上**に挿入（`P` 同様）。コードブロック貼付に最適 |
| `<C-r><C-p>{r}` | リテラル + **インデント整形**（`[<MiddleMouse>` 相当）— 貼付内容のインデントを現在行に合わせる |
| `<C-r>=expr`    | Vim 式を評価して結果を挿入                                  |
| `<C-r><C-w>`    | カーソル下の word を挿入                                    |
| `<C-r><C-a>`    | カーソル下の WORD を挿入                                    |

### 補完

| Key          | 動作                                                  |
|--------------|-------------------------------------------------------|
| `<C-n>`      | 次のキーワード補完候補                                |
| `<C-p>`      | 前のキーワード補完候補                                |
| `<C-x><C-o>` | Omni 補完（filetype 認識）                            |
| `<C-x><C-f>` | ファイルパス補完                                      |
| `<C-x><C-l>` | 行全体補完                                            |
| `<C-x>s`     | スペル候補                                            |

### 隣接行から 1 文字コピー

| Key      | 動作                                                  |
|----------|-------------------------------------------------------|
| `<C-y>`  | **上の行**の同列の文字を挿入                          |
| `<C-e>`  | **下の行**の同列の文字を挿入                          |

### インデント

| Key      | 動作                                                  |
|----------|-------------------------------------------------------|
| `<C-t>`  | 1 shiftwidth インデント                               |
| `<C-d>`  | 1 shiftwidth デデント                                 |
| `0<C-d>` | インデント全削除（カーソルは行頭）                    |
| `^<C-d>` | インデント削除、次行を復元                            |

### リテラル / 特殊

| Key            | 動作                                                            |
|----------------|-----------------------------------------------------------------|
| `<C-v>{char}`  | 文字をリテラル挿入（例: `<C-v><Tab>` で生タブ）                  |
| `<C-k>{a}{b}`  | digraph 挿入（[digraphs](14-digraphs) 参照）                    |
| `<C-q>`        | `<C-v>` と同じ（`<C-v>` がペーストに mapped されてる時）         |

## 使い分け

- **`<BS>` vs `<C-w>` vs `<C-u>`**: `<BS>` = 1 文字、`<C-w>` = 1 単語、`<C-u>` = 行頭まで。可能な限り大きい単位を使う — 20 回 backspace は危険信号
- **`<Esc>` vs `<C-c>`**: 脱出としては同じだが `<C-c>` は **`InsertLeave` autocmd をスキップ**（LSP やスニペット終了処理）。即座に抜けたいなら `<C-c>`
- **`<C-o>` vs 出てから戻る**: `<C-o>dd` で行削除して Insert に残る。`<C-o>` 無しだと `<Esc>dda` で 4 打 + 文脈切替。打ちながらの小ジャンプ・検索・削除には `<C-o>`
- **`<C-r>"` vs Normal モードの `p`**: `<C-r>` は Insert モードを抜けずにペースト。`<C-r>0` で直前のヤンクを抜けずに挿入、出てから `p` するのは抜けてしまった時
- **`<C-r>"` vs `<C-r><C-r>"`**: 二重版は**リテラル**挿入 — レジスタ内の制御文字を実行せず文字として入れる（リテラル `<Tab>` はタブ文字として残る）。`'textwidth'` `'formatoptions'`・自動インデントは両方とも依然適用される。キーストローク的なテキストを含むレジスタには二重を使う
- **`<C-r><C-o>` vs `<C-r><C-p>`**: どちらもリテラル挿入で mapping bypass。**`<C-r><C-o>` は自動インデント抑止**（既にインデント済みのコードを貼るとき）。**`<C-r><C-p>` はインデント整形**して現在行のインデントに合わせる（周囲のインデントに揃えたいとき）。インデント挙動を制御したいならどちらかを選ぶのが安全
- **`<C-n>` vs LSP 補完**: `<C-n>` は現バッファのキーワード補完（内蔵）、LSP は意味補完。併存可 — `<C-Space>` を LSP に振り、`<C-n>` をフォールバックにする構成が多い

## 実例

```text
打ち間違えた単語を修正:
  ...打ってる...  あれ違う  →  <C-w>  →  打ち直し

コードの真ん中にパスを挿入:
  func("<C-x><C-f>...")    ファイル補完

最後のヤンクをインライン挿入:
  echo "<C-r>0";

Insert を抜けずに 1 Normal コマンド:
  ...打ってる...  →  <C-o>dd  →  打ち続ける

数式をインライン評価:
  pi = <C-r>=3.14*2<CR>
```

## 落とし穴

- `<C-c>` は autocmd をスキップ。スニペット/LSP の `InsertLeave` 終了処理に依存しているなら `<Esc>` を使うか `<C-Esc>` を mapping
- Insert の `<C-r>` は Normal の `<C-r>`（redo）と**別物**。同じキーで違うモード
- Insert の `<C-d>` はデデント。Normal の `<C-d>` はスクロール。同じキー、別世界
- Insert の `<C-u>` は行頭まで削除、`:` cmdline の `<C-u>` はコマンド全体削除。混同しない
- `<C-r>=` は Vim 式を評価: `<C-r>=&shiftwidth<CR>` で現在の shiftwidth を挿入。強力だがエラーが出やすい — シングルクォートのエスケープが特殊
