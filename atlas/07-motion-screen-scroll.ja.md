# 画面位置・スクロール

カーソルを画面内で動かす、または画面ごとスクロールする。視覚的文脈を失わずにナビゲートする要。

## コマンド一覧

### 画面内カーソル移動

| Key   | 動作                                               |
|-------|----------------------------------------------------|
| `H`   | High — 画面の最上行（最初の非空白）                |
| `M`   | Middle — 画面の中央行                              |
| `L`   | Low — 画面の最下行                                 |
| `{n}H`| 画面の**上から `n` 行目**（`5H` で画面 5 行目）    |
| `{n}L`| 画面の**下から `n` 行目**                          |

### 画面のみスクロール（カーソル維持）

| Key      | 動作                                            |
|----------|-------------------------------------------------|
| `<C-e>`  | **ウィンドウ**をバッファ内で 1 行下へスクロール — 画面上ではテキストが**上**へ動く。カーソルはバッファ行に残り、表示範囲を外れると追従 |
| `<C-y>`  | **ウィンドウ**をバッファ内で 1 行上へスクロール — 画面上ではテキストが**下**へ動く |

### カーソル + 画面を一緒に

| Key      | 動作                                            |
|----------|-------------------------------------------------|
| `<C-d>`  | 半画面下                                        |
| `<C-u>`  | 半画面上                                        |
| `<C-f>`  | 1 画面下（ページ）                              |
| `<C-b>`  | 1 画面上                                        |

### ウィンドウ内のカーソル位置調整

| Key   | 動作                                                  |
|-------|-------------------------------------------------------|
| `zz`  | カーソル行をウィンドウ中央に来るよう再描画（カーソル自体は動かない） |
| `zt`  | カーソル行をウィンドウ上端に来るよう再描画（カーソル自体は動かず、ウィンドウが動く） |
| `zb`  | カーソル行をウィンドウ下端に来るよう再描画（カーソル自体は動かず、ウィンドウが動く） |
| `z.`  | `zz` 同様、最初の非空白で                             |
| `z<CR>` | `zt` 同様、最初の非空白で                           |
| `z-`  | `zb` 同様、最初の非空白で                             |

### 水平方向（`nowrap` 時）

| Key   | 動作                                       |
|-------|--------------------------------------------|
| `zh`  | 表示窓を左へ 1 列パン                       |
| `zl`  | 表示窓を右へ 1 列パン                       |
| `zH`  | `zh` と同方向に半ウィンドウ幅                |
| `zL`  | `zl` と同方向に半ウィンドウ幅                |

## 使い分け

- **`<C-d>` vs `<C-f>`**: 半画面 vs 全画面。`<C-d>` は前画面の半分が見えたままで文脈追跡しやすい。`<C-f>` は速いが skim 向け。日常使いは `<C-d>`/`<C-u>` が基本。
- **`H`/`M`/`L` vs `<C-d>`**: `H`/`M`/`L` は**現在画面内**で移動（スクロールなし、文脈完全保持）、`<C-d>` はスクロール。地図を保ちたい短距離移動には `H`/`L`
- **`zz` vs `zt` vs `zb`**: いずれもカーソルはそのままで画面を調整。`zz` 中央（バランス）、`zt` 上端（**下方**の文脈最大、検索後の「これからどうなる」確認に）、`zb` 下端（**上方**の文脈最大、call chain を逆辿る時に）
- **`<C-e>`/`<C-y>` vs `<C-d>`/`<C-u>`**: `<C-e>` は画面のみスクロール、カーソルは元のバッファ行に残る（表示範囲を外れると追従）。`<C-d>` はカーソルも動く。読むだけなら `<C-e>`、編集予定があるなら `<C-d>`
- **`{n}H` vs `{n}G`**: `{n}H` は**画面**上端から `n` 行、`{n}G` は**ファイル**の `n` 行目。参照点が違う

## 文法での位置づけ

スクロール系はほぼ operator と組まない（`d<C-d>` は意味なし）。`H` `M` `L` は motion なので組める:

- `dH`  — カーソルから画面上端まで削除
- `yL`  — カーソルから画面下端までヤンク
- `=H`  — カーソルから画面上端まで自動整形

## 実例

```text
検索ジャンプ後:           n  →  zt   （マッチを上端に、続きを確認）
コードを上から読む:       H  →  読む  →  L  →  読む  →  <C-d>（進む）
現在行を中央へ:           zz
カーソル不動でスクロール: <C-e><C-e>  （2 行下、押し出されるまでカーソル付随）
```

## 落とし穴

- `<C-f>` は 1 画面飛ぶので方向感覚を失いやすい。日常は `<C-d>` を選ぶ。
- `zz`/`zt`/`zb` はカーソルを動かさない — 画面のみ調整。`H`/`M`/`L` と混同すると画面が跳んでカーソル位置で何も起きない
- `zh`/`zl` は `:set nowrap` 時のみ意味を持つ。wrap オン（デフォルト）では機能しない
- `H`/`L` の count は**画面端**からの距離 — `5H` は「画面の 5 行目」、「カーソルから 5 行上」ではない
- `<C-d>`/`<C-u>` に count を付けると**副作用**がある: `[count]<C-d>` は `'scroll'` オプションを `[count]` に**設定**してしまい、以降のこのウィンドウの `<C-d>`/`<C-u>` 動作量が変わる。意図的に変えるなら `:set scroll=10` の方が綺麗
- `'scrolloff'` が非 0 だと **`H` / `L` / `zt` / `zb` がすべて影響を受ける** — `H` は実際の上端より `scrolloff` 行下に着地、`zt` は行 1 にカーソルを固定できない、など
