# ウィンドウ — 分割ビュー

**ウィンドウ**はバッファの表示枠。分割で複数のバッファ（または同一バッファの別位置）を並べて見られる。`<C-w>` プレフィックスが全ウィンドウ操作を司る。

## コマンド一覧

### 作成

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:sp [{file}]`    | 水平分割（現バッファか `{file}`）                   |
| `:vsp [{file}]`   | 垂直分割                                            |
| `:new`            | 水平分割で空バッファ                                |
| `:vnew`           | 垂直分割で空バッファ                                |
| `<C-w>s`          | 水平分割（`:sp` と同じ）                             |
| `<C-w>v`          | 垂直分割（`:vsp` と同じ）                            |
| `<C-w>n`          | 新規空水平分割                                      |
| `<C-w>f`          | カーソル下のファイルを水平分割で開く                |
| `<C-w>F`          | カーソル下のファイル（+ 行番号）を水平分割で         |
| `<C-w>gf`         | カーソル下のファイルを新タブで                       |

### 移動

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `<C-w>h/j/k/l`    | 左 / 下 / 上 / 右のウィンドウへ                      |
| `<C-w>w`          | 次のウィンドウへ                                    |
| `<C-w>W`          | 逆方向に巡回                                        |
| `<C-w>p`          | 直前にアクセスしたウィンドウへ                       |
| `<C-w>t`          | 左上のウィンドウ                                    |
| `<C-w>b`          | 右下のウィンドウ                                    |

### 配置

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `<C-w>H`          | 現ウィンドウを左端へ移動                            |
| `<C-w>J`          | 下端へ                                              |
| `<C-w>K`          | 上端へ                                              |
| `<C-w>L`          | 右端へ                                              |
| `<C-w>r` / `<C-w>R` | ウィンドウ回転                                     |
| `<C-w>x`          | 次のウィンドウと交換                                |

### サイズ変更

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `<C-w>+`          | 高さを増やす                                        |
| `<C-w>-`          | 高さを減らす                                        |
| `<C-w>>`          | 幅を増やす                                          |
| `<C-w><`          | 幅を減らす                                          |
| `<C-w>=`          | 全ウィンドウを均等化                                |
| `<C-w>_`          | 高さ最大化                                          |
| `<C-w>|`          | 幅最大化                                            |
| `{n}<C-w>_`       | 高さを `n` 行に                                     |
| `:resize {n}`     | 高さ設定                                            |
| `:vertical resize {n}` | 幅設定                                          |

### 閉じる

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `<C-w>c` or `:close` | 現ウィンドウを閉じる                              |
| `<C-w>o` or `:only` | 他のウィンドウをすべて閉じる                       |
| `<C-w>q` or `:quit` | 現ウィンドウを quit                                |

### 全ウィンドウで操作

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:windo {cmd}`    | 現タブの全ウィンドウで `{cmd}` を実行                |

## 使い分け

- **`:sp` vs `:new`**: `:sp` は同じバッファを分割表示、`:new` は新規空バッファ。同じファイルを 2 ヶ所見たいなら `:sp`、スクラッチパッドなら `:new`
- **`<C-w>w` vs `<C-w>{hjkl}`**: `w` は順番巡回、`hjkl` は空間移動。位置が分かれば方向キー、「とりあえず別へ」なら `w`
- **`<C-w>c` vs `:bd`**: `<C-w>c` は**ウィンドウ**を閉じるがバッファは保持、`:bd` はバッファを閉じる（紐づくウィンドウも）。整理目的なら `<C-w>c`、削除なら `:bd`
- **`<C-w>=` vs 手動リサイズ**: 最初に `<C-w>=` で均等化してから微調整。`<C-w>>` 連打を節約
- **ウィンドウ vs タブ**: ウィンドウは**並列比較・編集**用、タブは**別ワークスペース**用（別機能・別レイアウト）。ファイルを多重化するためにタブを使わない — それはバッファ一覧の仕事

## 実例

```text
水平分割:                     :sp
ファイル指定で分割:           :sp other.c
垂直分割でファイル:           :vsp config.json
ウィンドウを左端へ:           <C-w>H
サイズ均等化:                 <C-w>=
他を全部閉じる:               <C-w>o
垂直幅 80 に:                 :vertical resize 80
ファイルを新分割で開く:       <C-w>f       （<C-w>f か <C-w>F を使う; 素の gf は現ウィンドウで開く）
```

## Web 環境について

Web Vim エミュレーションは多くが単一ウィンドウ。ウィンドウ分割は適用外。

## 落とし穴

- `<C-w>o`（他を閉じる）は `'hidden'` 無効で他に未保存バッファがあると**拒否される**。強制するなら `:only!`（未保存変更は失われる）。保存したいなら先に `:wa`
- `<C-w>{HJKL}` はウィンドウ自体を移動、`<C-w>{hjkl}` はナビゲーション。小文字でナビ、大文字で移動
- 最後のウィンドウを `<C-w>c` で閉じると Vim も終了。バッファを消したいが Vim は残したいなら `<C-w>o` か `:bd`
- ウィンドウローカル設定（`'wrap'` `'cursorline'` 等）は `:split` 時に**現ウィンドウから継承**される。違う設定にしたいなら分割後に明示設定
- `<C-w>` 自体がターミナルで食われることがある（tmux prefix 衝突）。必要なら remap
