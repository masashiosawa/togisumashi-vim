# Insert モードへの入り方

Normal から Insert へ切り替える方法はいくつもある。それぞれ開始位置が違うので、入力前にカーソル移動するキーストロークが省ける。

## コマンド一覧

| Key       | 動作                                                              |
|-----------|-------------------------------------------------------------------|
| `i`       | カーソル**前**で挿入                                              |
| `a`       | カーソル**後**で挿入（append）                                    |
| `I`       | 行の最初の**非空白**で挿入                                        |
| `A`       | 行**末**で挿入                                                    |
| `o`       | **下**に新行を開けて挿入                                          |
| `O`       | **上**に新行を開けて挿入                                          |
| `s`       | 1 文字置換 — 文字を削除して挿入（`cl` 同等）                       |
| `S`       | 1 行置換 — 行内容を削除して挿入（`cc` 同等）                       |
| `gI`      | 列 1（インデントを無視、物理的行頭）で挿入                         |
| `c{motion}` | motion 範囲を削除して挿入                                       |
| `cc`      | 行全体を置換                                                      |
| `C`       | 行末まで置換                                                      |

## 使い分け

- **`i` vs `a`**: `i` はカーソル**前**、`a` は**後**で挿入。単語末尾から打ち始めたいなら `a` の方が `l`+`i` より 1 打少ない
- **`I` vs `0i`**: `I` は最初の非空白へ + Insert、`0i` は列 0 へ。インデント付きコードでは `I` がほぼ常に正解
- **`A` vs `$a`**: `A` は `$a` より 1 打少なく同じ結果。無条件に `A` を使う
- **`o` vs `O`**: `o` は下、`O` は上に新行。`'autoindent'` 有効なら両者ともインデントを引き継ぐ — ブロック内に文を足す時に便利
- **`s` vs `r`**: `s` は文字削除 + Insert（複数文字置換）、`r` は 1 文字置換で Normal 維持。タイポ修正は `r`、1 文字を多文字にするなら `s`
- **`S` vs `cc`**: 同義。`S` は 1 キー版、`cc` は文法整合版
- **`C` vs `c$`**: 同義。`C` は 1 キー版
- **`gI` vs `I`**: ほぼ不要。`gI` はインデント無視で絶対列 1。空白が意味を持つ書式編集の時だけ
- **`gi`（最後の挿入位置から再開）**: 本記事では扱わない — [marks-and-jumps] 参照。`gi` は最後に Insert を抜けた位置（`` `^ ``）から Insert モードを再開する

## 文法での位置づけ

`i` `a` `I` `A` `o` `O` は**挿入コマンド**（`{insert}{text}<Esc>` として動く）。入力テキストごと `.` で再現可能:

- `cwBar<Esc>` の後 `.` で「カーソル位置の単語を Bar に置換」を繰返し
- `oconst x = 1;<Esc>` の後 `.` で `const x = 1;` 行を追加

## 実例

```text
行末にセミコロン:        A;<Esc>
上に新行追加:            O    let foo = 1;<Esc>
単語置換:                ciw  bar<Esc>
インデント行の先頭:      I    return<Esc>
1 文字修正:              r    x       （1 文字を x に置換）
1 文字を多文字に:        s    hello<Esc>   （文字を削除して "hello" を挿入）
単語末尾で追記:          ea   <text><Esc>
```

## 落とし穴

- `<Esc>` 後、カーソルは停止位置から**1 つ左**に戻る。仕様だが（Normal モードの位置に合わせるため）初心者は驚く
- `s` と `cc` は削除文字を無名レジスタに残す。続けて `p` すると直前の削除内容がペーストされる
- `o` `O` は `'autoindent'`/`'smartindent'`/`'cindent'` を尊重して改行。生の改行が欲しいなら `:set noai`
- `gI` はほぼ使わないが、存在は知っておく — 「`I` がなぜ空白を飛ばすのか」の理解に直結
- インデントを継承しない空行を直下に作るには `Go<Esc>`（または `:set noai` してから `o`）
