# ヤンク・ペースト

テキストをレジスタにコピーして、別の場所に貼る。Vim の「コピー」は**ヤンク**と呼ぶが、概念は同じ。

## コマンド一覧

### ヤンク（コピー）

| Key      | 動作                                                            |
|----------|-----------------------------------------------------------------|
| `y{motion}` | motion 範囲をヤンク                                            |
| `yy`     | 行全体をヤンク                                                   |
| `Y`      | 行全体をヤンク（純正） — 多くの vimrc が `y$` に remap            |
| `:[range]y [reg]` | range をレジスタへヤンク                               |

### ペースト

| Key      | 動作                                                            |
|----------|-----------------------------------------------------------------|
| `p`      | カーソルの**後**にペースト（linewise: 下の行）                   |
| `P`      | カーソルの**前**にペースト（linewise: 上の行）                   |
| `gp`     | ペースト後、カーソルをペースト末尾の**後**へ                     |
| `gP`     | 前にペーストしてカーソルを後ろへ                                 |
| `]p`     | カーソルの**後**に自動インデント付きペースト                     |
| `[p`     | カーソルの**前**に自動インデント付きペースト                     |
| `]P`     | `[p` と同じ（自動インデント付き前置ペースト）— variant           |
| `[P`     | `[p` と同じ                                                      |
| `{n}p`   | `n` 回ペースト                                                  |
| `"{r}p`  | レジスタ `{r}` からペースト                                      |
| `:[line]put [reg]` | `[line]` の後にレジスタを linewise put             |

## 使い分け

- **`yy` vs `Y`**: Vim では `Y` ≡ `yy`（行全体）。**Neovim のデフォルトは `Y` ≡ `y$`**（`D` `C` と対称）。vimrc / Vim バージョンを確認
- **`p` vs `P`**: `p` は後、`P` は前。linewise なら `p` で下、`P` で上
- **`p` vs `gp`**: ペースト後、`p` はカーソルがペースト末尾。`gp` は**1 つ先**に — 連続ペーストする時に便利
- **`p` vs `]p`**: `p` は生のまま（ヤンク時のインデント保持）、`]p` は周囲コードに合わせて再インデント。コードを別文脈に移す時は `]p`
- **`yyp` vs `:copy`**: `yyp` で行複製、`:copy .`（`:t .` でも）も同じ。`yyp` の方が速いが、range なら `:co` が活躍（`:5,10co.` で 5-10 行目を現行の後にコピー）
- **無名 `""` vs システム `"+`/`"*`**: `p` は無名レジスタ（削除で上書きされる）。`"+` はシステムクリップ — X11/Wayland では **CLIPBOARD** 選択（Ctrl+C/V）、macOS/Windows では pasteboard（`"*` は `"+` の別名）。`"*` は X11/Wayland では **PRIMARY** 選択（中ボタンペースト）— `"+` とは別の selection。**Vim では `+clipboard` ビルド、Neovim では provider**（`pbcopy`/`wl-copy`/`xclip`）が必要。`'clipboard'=unnamedplus` で `""` が自動的に `"+` を使う

## 実例

```text
行複製:                    yyp
5 行コピーして末尾にペースト: 5yy  →  G  →  p
システムクリップへヤンク:    "+yy
システムクリップから貼る:    "+p
関数を移動:                 da{  →  G  →  p     （囲み削除 → ペースト）
コード貼り付け:              ]p   再インデント付き
3 回ペースト:                3p
```

## 落とし穴

- 無名レジスタは**削除で上書き**される（`c` `s` `x` 含む）。ヤンク → `dw` → `p` だとヤンクが消えてる。`"0p`（ヤンクレジスタ）か名前付きレジスタ `"ay` を使う。**注意**: `"0` は**無修飾の**ヤンクのみで更新される（`yy`、`yiw` 等）。`"ay` のような名前付きヤンクは `"a` にだけ書き込まれ `"0` には入らないので、`"0p` では取り戻せない — `"ap` を使う
- ファイル最終行で `yy` 後の `p` は新行を**下**に作り、それが新たな最終行になる。`scrolloff` 境界に隠れた場合は `<C-l>` か `zz` で再描画
- `Y` は最大の罠 — 純正は `yy` だがチュートリアルは `y$` を前提にする。どちらかに統一する
- `]p` はペースト内容のインデントを現在行に合わせて調整 — `'autoindent'` `'smartindent'` には依存しない。これらが無くても `p` とは別の動作
- linewise ヤンクを行内で `P` すると新行が上に追加、charwise なら行内挿入。ペーストの様式はヤンク時の様式に従う
