# テキストオブジェクト — 境界のある領域

「カーソル位置との関係」でなく「**何であるか**」（単語、クォート、関数本体）でテキストを指定する。Vim 合成性の真骨頂。

## コマンド一覧

形式は常に `i{x}`（**inner**: 内側のみ）または `a{x}`（**a**: 内側 + 区切り）。

### word と WORD

| オブジェクト | 意味                                |
|--------------|-------------------------------------|
| `iw` `aw`    | word / word + 隣接空白              |
| `iW` `aW`    | WORD（空白区切り）                  |

### 文と段落

| オブジェクト | 意味                                |
|--------------|-------------------------------------|
| `is` `as`    | 文 / 文 + 末尾空白                  |
| `ip` `ap`    | 段落 / 段落 + 空白行                |

### クォート

| オブジェクト | 意味                                                        |
|--------------|-------------------------------------------------------------|
| `i"` `a"`    | ダブルクォート内 / を含む                                   |
| `i'` `a'`    | シングルクォート内 / を含む                                 |
| `` i` `` `` a` `` | バッククォート内 / を含む                              |

### 括弧

| オブジェクト                          | 意味                                            |
|---------------------------------------|-------------------------------------------------|
| `i(` `a(` or `i)` `a)` or `ib` `ab`   | 丸括弧                                          |
| `i[` `a[` or `i]` `a]`                | 角括弧                                          |
| `i{` `a{` or `i}` `a}` or `iB` `aB`   | 中括弧（Block）                                 |
| `i<` `a<` or `i>` `a>`                | 山括弧                                          |
| `it` `at`                             | HTML/XML タグ（`<tag>...</tag>`）              |

## 使い分け

- **`i`（inner） vs `a`（a/around）**: `i` は**内容のみ**（区切り含まず）、`a` は区切りと一部末尾空白を含む。中身の作り直しなら `i`、構造ごと削除なら `a`
- **`iw` vs `iW`**: `iw` は句読点で止まる（`foo.bar` は 2 word）、`iW` は句読点を含む（1 WORD）。パス・URL・ドット付き識別子には `iW`
- **`iw` vs `i"`**: `iw` はカーソル位置の word を文脈関係なく選択、`i"` は最寄りの囲みクォート内を選択（カーソルがクォート間でなくても行内で探索）。中身を取りたいなら `i"`、トークンなら `iw`
- **`ap` vs `ip`**: `ap` は**末尾**の空白行を含む。無ければ**先頭**の空白行へフォールバック。`ip` は空白行に触れない。段落の綺麗な削除には `ap`。`as`・`aw`/`aW` も同じ「末尾優先・先頭フォールバック」ルール — **位置で決まる**（カーソルが来た方向は無関係）。（`is` / `ip` / `iw` は inner 形 — 周囲の空白は含まない）
- **`ib`/`iB` vs `i(`/`i{`**: 別名。`ib` ≡ `i(`、`iB` ≡ `i{`。記号形は明瞭、文字形は指の位置で
- **テキストオブジェクト vs motion**: text object は領域を境界で指定（`diw` は word の中ほどから打ってもよい）、motion はカーソルから目標へ（`dw` だと word 前半が残ることあり）。「これを操作」なら常に text object
- **`it` vs `i<`**: `it` は**対応する HTML/XML タグの中身**（`<a>...</a>` → `...`）。`i<` は汎用の山括弧テキストオブジェクトで、任意の `<` `>` ペア間（ネスト対応）を選ぶ。仕事が違う — タグ本体は `it`、生の山括弧内容は `i<`

## 文法での位置づけ

テキストオブジェクトは operand（operator ではない）。あらゆる operator が後に続ける:

- `d` + オブジェクト: `daw`、`diw`、`di"`、`dap`、`di{`、`dat`
- `c` + オブジェクト: `ciw`、`ci(`、`cit`、`cip`
- `y` + オブジェクト: `yi"`、`ya{`、`yip`
- `>` `<` + オブジェクト: `>ap`、`<i{`
- Visual + オブジェクト: `vi"`、`vap`、`vi{`

## 実例

```text
文字列の中身を置換:        ci"     "old"   →   "new"
関数本体を削除:            di{
関数全体を削除:            da{      括弧も含む
段落 + 空白行を選択:       vap
HTML タグの中身を置換:     cit
引数を削除:                di(
クォート内 URL を置換:     ci"  https://...<Esc>
```

## 落とし穴

- テキストオブジェクトは**最も近い**囲みを探す。ネストしたクォート/括弧では最内側が勝つ
- デフォルトの `i"` は**現在行内**のみ探索 — 複数行文字列には `targets.vim` 等のプラグインが必要
- `as`（around sentence）は Vim の文定義に従う: `.` `!` `?` + 行末 or 空白/タブ 1 つ（`'cpoptions'` に `J` 含む時のみ 2 つ）。コードコメントでは脆い、コードには `ap`
- `it`/`at` は**テキスト的**タグマッチ — `<tag>...</tag>` ペアを文字列として探す。`'filetype'` や syntax に依存しない。自己閉じタグ（`<br/>`）や属性内の `<` `>` で誤検出することがある
- `ip`/`ap` は空白行を段落境界と見なす — 1 行の空白で段落が区切られる
