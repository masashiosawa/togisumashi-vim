# マーク・ジャンプ履歴

位置を覚えて戻る。カーソル履歴を辿る。「さっきそこに居た」の要。

## コマンド一覧

### マーク設定

| Key            | 動作                                                            |
|----------------|-----------------------------------------------------------------|
| `m{a-z}`       | **ローカル**マーク `{a-z}` 設定（現バッファのみ）               |
| `m{A-Z}`       | **グローバル**マーク `{A-Z}` 設定（ファイルパスも記憶）         |

### マークへジャンプ

| Key            | 動作                                                            |
|----------------|-----------------------------------------------------------------|
| `` `{a-z} ``   | マークの**正確な位置**（行 + 列）へ                              |
| `'{a-z}`       | マーク**行**の最初の非空白へ                                    |
| `` `{A-Z} ``   | グローバルマークへ（必要ならファイルを開く）                    |

### 特殊マーク

| マーク    | 意味                                                       |
|-----------|------------------------------------------------------------|
| `` ` ` `` | 最後のジャンプ前の位置（`''` も同等）                      |
| `` `" ``  | ファイルから最後に出た位置                                 |
| `` `[ `` `` `] `` | 最後にヤンク/変更したテキストの開始/終了             |
| `` `< `` `` `> `` | 最後の visual 選択の開始/終了                         |
| `` `. ``  | 現バッファでの最後の変更位置                               |
| `` `^ ``  | 最後の挿入位置                                             |
| `` `0 ``     | Vim を最後に終了した時のカーソル位置                |
| `` `1 ``–`` `9 `` | それ以前の Vim セッション終了時の位置（番号が大きいほど古い） |

### ジャンプリストと changelist

| Key      | 動作                                                            |
|----------|-----------------------------------------------------------------|
| `<C-o>`  | ジャンプリストを**後方**へ                                      |
| `<C-i>`  | ジャンプリストを**前方**へ（`<Tab>` と同等）                    |
| `g;`     | changelist を**後方**へ                                         |
| `g,`     | changelist を**前方**へ                                         |
| `gi`     | 最後の挿入位置へ + Insert モードに入る                          |
| `:marks` | 全マーク一覧                                                    |
| `:jumps` | ジャンプリスト一覧                                              |
| `:changes` | changelist 一覧                                               |

## 使い分け

- **`` `{a} `` vs `'{a}`**: バックティックは**正確な列**へ、シングルクォートは**行頭（最初の非空白）**へ。手術的に戻るならバックティック、「あの行を見せて」ならシングル
- **小文字 `m{a}` vs 大文字 `m{A}`**: 小文字 = 現バッファ限定（ファイル切替で消える）。大文字 = グローバル、`~/.viminfo` でセッション跨ぎ保持。プロジェクト跨ぎのブックマークには大文字
- **`<C-o>` vs `''`**: `''` は「ジャンプ元に戻る」の短縮（最新の 1 つ）。`<C-o>` は履歴を 1 つずつ遡る
- **`<C-o>` vs `g;`**: `<C-o>` は**ジャンプリスト**（検索/ジャンプの履歴）、`g;` は **changelist**（編集履歴）。到達方法に合わせて選ぶ
- **`gi` vs `` `^ ``**: 両者とも最後の挿入位置。`gi` はさらに Insert モードに入る。続きを打ちたいなら `gi`
- **マーク vs `:tag`**: マークは自分で明示設定する個人ブックマーク、タグは tags ファイル由来の言語シンボルジャンプ。「ここを覚えて」にはマーク、「定義に飛ぶ」にはタグ

## 「ジャンプ」と認識されるもの

Vim は以下の motion でジャンプリストに記録する（抜粋）:

- `G`、`{n}G`、`gg`
- `/`、`?`、`n`、`N`
- `*`、`#`、`gd`
- `H`、`M`、`L`
- `(`、`)`、`{`、`}`
- `%`
- バッファ/ウィンドウ切替

1 歩 motion（`h` `j` `k` `l` `w` `e`）はジャンプリストに**記録されない**。

## 実例

```text
マーク + 復帰:         mA  ...  別ファイルへ移動  ...  `A  → 戻る
編集 + 復帰:           ...ここで編集...  →  ファイル切替  →  gi  → カーソルそこへ、Insert
コードを読む:          gd → 定義を見る → <C-o> → 呼出元へ戻る
最終 visual:           gv   直前の visual を再選択
```

## 落とし穴

- グローバルマークの永続性は `viminfo`（Neovim では `shada`）で実現。`:set viminfo=` で無効化すると `m{A-Z}` が永続化しない
- `'{a}` は常に最初の非空白に着地 — マークの列情報は無音で捨てられる。列が必要ならバックティック
- `<C-i>` と `<Tab>` はターミナルでは**同じ文字**。`<Tab>` をマップするとジャンプリストの `<C-i>` が奪われる
- ジャンプリストは**ウィンドウ単位**であってバッファ単位ではない。ウィンドウ分割で新しいジャンプリストが始まる
