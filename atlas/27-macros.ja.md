# マクロ — 録音と再生

繰り返し構造編集における Vim の決定打。コマンド列を 1 回録音し、任意回数再生する。マクロは**レジスタ**（`a`〜`z`）に格納されるため、複数保持・セッション跨ぎでも再利用できる。

## コマンド一覧

| Key             | 動作                                                          |
|-----------------|---------------------------------------------------------------|
| `q{a-zA-Z}`     | レジスタ `{a-z}` に録音開始（小文字は上書き、大文字は追記）    |
| `q`             | 録音停止（録音中）                                            |
| `@{a-z}`        | レジスタ `{a-z}` のマクロを再生                               |
| `@@`            | 最後に使ったマクロを再生                                       |
| `{n}@{a}`       | マクロを `n` 回再生                                           |
| `q{A-Z}`        | 既存マクロに**追記**（大文字）                                |
| `:@{a}`         | マクロを ex コマンドとして実行                                |
| `:[range]normal @{a}` | `[range]` の全行でマクロ実行                              |
| `:g/pat/normal @{a}` | `pat` にマッチする全行でマクロ実行                          |

## 使い分け

- **マクロ `@a` vs ドット `.`**: `.` は**最後の単一編集だけ**を再生（1 つの operator+motion+insert）。マクロは motion / ex コマンドを含む任意列を再生。1 動詞で済むなら `.` の方が速い
- **マクロ vs `:s/.../.../g`**: パターンベース変換は substitute が速い（`s/foo/bar/g`）。マクロは**位置依存**または**1 箇所に複数手順**、**周辺行と連動**する変換で有利
- **マクロ vs `:g/pat/cmd`**: `:g` は 1 ex コマンドをマッチ行に適用、マクロは任意列を再生。組合せ可: `:g/pat/normal @a` で「global 反復 ＋ マクロ本体」
- **マクロ vs Visual block 編集**: 連続行の列編集なら Visual block（`<C-v>` + `I`/`A`/`c`）が簡単。行ごとに編集内容が変わる、または非隣接行を処理するならマクロ
- **`qa` vs `qA`**: 小文字は**上書き**、大文字は**追記**。途中で修正したい時は `qA` でゼロからやり直さずに済む

## 仕組み

マクロは**キーストロークをそのまま保持するレジスタ**でしかない。Normal モードで打てるものは全部録音可能。録音中はステータスラインに `recording @{a}` が表示される。`q` で停止。

レジスタなので編集できる: `:let @a="cw\<Esc>"` でプログラム的に組める（ダブルクォート + `\<Esc>` で本物の Esc キーコードを埋め込む — シングルクォートだとリテラル 6 文字 `<Esc>` が保存され動かない）。`"ap` でマクロ内容をバッファに貼って確認可能。

## 実例

```text
ゴール: "foo: 1" を全行 "FOO = 1;" に変換

  qa            a に録音開始
  0             行頭へ
  vey           単語を visual 選択してヤンク
  VU            行を visual 選択して大文字化
  f:            : を検索
  r=            = で置換
  $             行末
  a;<Esc>       ; を追記
  j             次行
  q             録音停止

  再生:      @a
  10 回:     10@a
```

```text
ゴール: "TODO" を含む行すべてでマクロ実行:

  :g/TODO/normal @a
```

## 落とし穴

- `j` で次行に進むマクロは最終行で止まる（次行が無いため）。対策: マクロ内で `j` するより `:[range]normal @a` を使う
- 小文字 `q{a}` で既存マクロを上書きすると**前の内容が消える**。追記したい場合は大文字 `qA`
- マクロはデフォルトで最初のエラーで停止（検索ミス等）。検索ミスを許したい場合はマクロ内で `e` フラグや `:silent!` を使う
- 録音内容は `:reg a` で確認（`:reg @a` ではない — `@` は実行用プレフィックスで、表示には不要）。マクロの生キーを手直し用に貼りたいなら Insert で **`<C-r><C-r>a`**（リテラル挿入 — `<Esc>` 等の制御文字を実行せず文字として入れる）。素の `<C-r>a` だと `<Esc>` が実行されて Insert から抜けてしまう。注意: `<C-r><C-r>` でも `'textwidth'` / `'formatoptions'` / 自動インデントは依然適用される — 長いマクロを自動折返し設定のバッファに貼るなら `:put a`（linewise で Insert の整形を一切受けない）の方が安全
- `'lazyredraw'` を設定すると長いマクロを多数行に走らせる時に再描画スキップで速度向上
- `@:` は `":` レジスタ（**最後の ex コマンド**）を実行する — 最後のマクロ再生とは別。`":` は実在の（読出専用）レジスタで、`<C-r>:` でもペースト可能
