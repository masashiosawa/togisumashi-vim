# 削除

テキストを消す。削除内容はデフォルトで**無名レジスタ**（`""`）に入る。複数行にまたがる（または改行を含む）削除、および `%`/`(`/`)`/`` ` ``/`/`/`?`/`n`/`N`/`{`/`}` motion を伴う削除（サイズ問わず）は番号レジスタ履歴 `"1`〜`"9` に入る。行内に収まる（改行を含まない）削除は **`"-`（small delete register）** へ。

## コマンド一覧

| Key      | 動作                                                            |
|----------|-----------------------------------------------------------------|
| `x`      | カーソル位置の文字を削除                                         |
| `X`      | カーソルの 1 つ前を削除                                          |
| `{n}x`   | 前方に `n` 文字削除                                              |
| `d{motion}` | motion 範囲を削除                                              |
| `dd`     | 行全体を削除（linewise）                                         |
| `D`      | カーソルから行末まで削除（`d$`）                                  |
| `:[range]d [reg]` | range をレジスタへ削除（例: `:1,10d a`）                |
| `J`      | 次行と結合（間に空白 1 つ）                                       |
| `gJ`     | 空白なしで結合                                                   |
| `:[range]j` | ex 形式の join                                                |

## 使い分け

- **`x` vs `dl`**: 同義。`x` の方が 1 打短いので優先
- **`X` vs `dh`**: 同義。`X` の方が短い
- **`dw` vs `daw` vs `diw`**: `dw` はカーソルから次単語先頭まで（半端な単語が残ることあり）。`daw` は単語 + 隣接空白を含めて削除、`diw` は単語のみで空白維持。きれいに消すなら `daw`
- **`D` vs `d$`**: 同義。`D` の方が速い
- **`dd` vs `V d`**: 同義。`dd` の方が速い。視覚で範囲を確認したい時だけ Visual
- **`J` vs `gJ`**: `J` は結合時に空白 1 つを挿入（散文・コードに賢い）、`gJ` は生で結合。すでに空白がある／空白を入れたくない（URL 断片等）には `gJ`
- **`d` vs `"_d`**: デフォルト `d` は無名レジスタを上書き、`"_d` は**ブラックホール**に削除（`""` の内容を保持）。ヤンクした内容を後でペーストしたいなら `"_d`
- **`d` vs `c`**: 両者とも削除。`d` は Normal で終わる、`c` は Insert に入る。すぐ打ち直すなら `c` の方が 1 打少ない

## 文法での位置づけ

`d` は operator。あらゆる motion / text object と合成可:

- `d3w` `d/foo<CR>` `dt;` `daw` `di(` `dap` `dG` `d%`

連打形 `dd` は linewise。明示的に `d_` でも可だが稀。

## 実例

```text
カーソル下の単語を削除:               daw
行末まで削除:                         D
次のセミコロンの手前まで:             dt;
次のセミコロン含めて:                 df;
関数本体を削除:                       di{
段落を削除:                           dap
ヤンクを保ったまま削除:               "_d{motion}
3 行結合:                             3J
```

## 落とし穴

- デフォルト `d` は無名レジスタを上書き。ヤンク → 削除 → `p` だと**削除内容**が貼られる（期待のヤンクではない）。`"_d` するか `"0p`（ヤンクレジスタ）から貼る
- `D` は `dd` と**別物**。`D` は行末まで、`dd` は行全体
- 最終行で `dd` するとその行が消え、上の行が新たな最終行になる。バッファが「行途中で終わる」わけではない。保存時の末尾改行は `'fixendofline'` / `'endofline'` で制御
- `J` は `'joinspaces'` 有効で文末句読点の後に**空白 2 つ**入れる。既定: **Vim は on、Neovim は off**。Vim で 1 つにするなら `:set nojoinspaces`
- multi-byte 文字（CJK・絵文字）の `x` は 1**文字**削除、1 バイトではない
