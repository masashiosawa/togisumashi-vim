# 外部コマンドとシェルフィルタ

Vim 内からシェルコマンドを実行する。バッファ内容をシェルプログラムに pipe する。エディタと OS をつなぐ橋。

## コマンド一覧

| 形式              | 効果                                                            |
|-------------------|-----------------------------------------------------------------|
| `:!{cmd}`         | `{cmd}` をシェル実行、出力をページャ表示                       |
| `:r!{cmd}`        | 実行して出力を**カーソル行の下**に挿入                          |
| `:[range]!{cmd}`  | range を `{cmd}` で**フィルタ**（置換）                          |
| `:.!{cmd}`        | 現在行を `{cmd}` でフィルタ                                     |
| `!{motion}{cmd}`  | (Normal) motion 範囲を `{cmd}` でフィルタ                       |
| `!!{cmd}`         | 現在行をフィルタ（Normal 形式）                                 |
| `{visual}!{cmd}`  | visual 選択をフィルタ                                           |
| `:{cmd}` 内       | （特殊文字）`%` = 現ファイル名、`#` = 代替ファイル              |
| `<C-z>`           | Vim をサスペンド（シェルで `fg` で復帰）                        |

## 使い分け

- **`:!` vs `:r!`**: `:!` は出力をページャ表示してから Vim に戻る、`:r!` は出力をバッファ内容として挿入。単発確認なら `:!`（`:!date`）、結果をテキストとして使うなら `:r!`
- **`:r!` vs `:[range]!`**: `:r!` は新規追加、`:[range]!` は既存行をコマンドでフィルタして**置換**。新規挿入は `:r!`、既存リストをソートするなら `:.!sort`
- **`!{motion}` vs `:[range]!`**: 同じ効果。Normal の `!{motion}` は行番号を考えずに済む、ex `:[range]!` はスクリプト的 range
- **`:!` vs `:terminal`**: `:!` は 1 回実行して出力。`:terminal` は永続シェルバッファ。繰返し作業や対話的コマンドには `:terminal`
- **`:!{cmd}` vs システムシェル**: `:!` は `'shell'` オプション（デフォルト `$SHELL`）を使う。特定シェルが必要なら `'shell'` 設定かフルパス

## `:!{cmd}` 内の特殊文字

| 文字 | 展開                                                            |
|------|-----------------------------------------------------------------|
| `%`  | 現在のファイル名                                                |
| `#`  | 代替ファイル名（前のバッファ）                                   |
| `##` | argument list の全ファイル                                       |
| `<cword>` | カーソル下の word（`expand('<cword>')`）。cmdline では **`<C-r><C-w>`** で直接挿入できる |
| `<cWORD>` | カーソル下の WORD（cmdline では `<C-r><C-a>`）              |
| `<cfile>` | カーソル下のファイル名（cmdline では `<C-r><C-f>`）         |
| `%:S`     | `shellescape()` 修飾子 — シェル用にクォート/エスケープ（`%` と組合せて使う） |

## 実例

```text
linter で現ファイル確認:        :!eslint %
現ファイルを実行:                :!python %
JSON 範囲を整形:                 :'<,'>!python -m json.tool
行をソート:                      :%!sort
行番号付与:                      :%!nl
段落の単語数:                    !ap （motion 範囲が確定して cmdline が開く）→ wc<CR>
外部ツールでパイプ:              :.!sed 's/foo/bar/'
Go ファイル再整形:               :%!gofmt
ディレクトリ一覧をバッファへ:    :r! ls -la
```

## Web 環境について

CodeMirror ベースの Web Vim（本サイトのドリルなど）では `:!` 系は**シェルを実行しない** — シェル自体が存在しない。本記事は実 Vim でマスターレベルに必須な機能として記載している。練習するにはローカルで実 Vim/Neovim を使う。

## 落とし穴

- `:!{cmd}` はコマンド完了まで Vim をブロック — デフォルトで非同期ではない。長時間のジョブは `:!{cmd} &`（バックグラウンド）か `:terminal`
- `%` の展開は**エスケープされない**。空白を含むファイル名で壊れる: `:S` 修飾子（`:!cmd %:S`）か `expand('%:p:S')` を使う
- `:[range]!` のフィルタはコマンドの stdout で**行を置換**。コマンドが失敗したり出力ゼロだと元内容が消える。`u` で復元
- `<C-z>` で Vim サスペンド、シェルで `fg` して復帰。初心者は Vim が落ちたと勘違いする
- `:!{cmd}` の出力はバッファ下のターミナル領域に出る — `:r!`（バッファに書く）とは別
