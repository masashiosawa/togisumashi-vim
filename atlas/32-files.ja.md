# ファイル — 開く・保存・移動

実 Vim はファイルシステム経由でファイルを扱う。Web 版 Vim エミュレーションにはファイルが無いため、本記事はドリル対象外の**マスター知識**として記す。

## コマンド一覧

### 開く / 読み込む

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:e {file}`       | `{file}` を編集（現バッファ）                       |
| `:e!`             | 変更を破棄して再読込                                |
| `:e .`            | netrw（内蔵ファイルブラウザ）を cwd で開く          |
| `:e ++enc=utf-8 {file}` | エンコーディング指定で開く                     |
| `:find {name}`    | `'path'` で `{name}` を検索                          |
| `:browse e`       | ファイルピッカー（GUI）                             |
| `gf`              | カーソル下のファイルを開く（`'path'` `'suffixesadd'` 使用）|
| `<C-w>f`          | カーソル下のファイルを水平 split で                 |
| `<C-w>gf`         | カーソル下のファイルを新タブで                       |

### 保存 / 書込

| コマンド          | 動作                                                |
|-------------------|-----------------------------------------------------|
| `:w`              | 現バッファを保存                                    |
| `:w {file}`       | バッファを `{file}` に書込（現バッファ名は変えない） |
| `:saveas {file}`  | `{file}` に書込 + 現バッファ名も切替                |
| `:[range]w {file}` | range を `{file}` に書込                            |
| `:[range]w >> {file}` | range を `{file}` に追記                         |
| `:wa`             | 全変更バッファを保存                                |
| `:wq`             | 保存して終了                                        |

### 終了

| コマンド  | 動作                                                |
|-----------|-----------------------------------------------------|
| `:q`      | 終了（変更があれば拒否）                            |
| `:q!`     | 強制終了（変更破棄）                                 |
| `:qa`     | 全終了                                              |
| `:qa!`    | 全強制終了                                          |
| `ZZ`      | `:wq` と同義                                         |
| `ZQ`      | `:q!` と同義                                         |

### 現ファイルの参照

| コマンドライン内 | 展開                                              |
|------------------|---------------------------------------------------|
| `%`              | 現在のファイル名                                   |
| `%:p`            | フルパス                                          |
| `%:h`            | ディレクトリ（head）                              |
| `%:t`            | ファイル名のみ（tail）                            |
| `%:e`            | 拡張子                                            |
| `%:r`            | 拡張子抜き（root）                                |
| `#`              | 代替ファイル                                      |

## 使い分け

- **`:e` vs `:r`**: `:e` は別ファイルにバッファを切替（表示を置換）、`:r` は現バッファにファイル内容を挿入。移動なら `:e`、マージなら `:r`
- **`:w` vs `:saveas`**: `:w {file}` は `{file}` に書くが現バッファ名は維持、`:saveas {file}` は書込 + バッファの正体を `{file}` に切替。「リネームして編集続行」なら `:saveas`
- **`:wq` vs `ZZ`**: 同義。`ZZ` は 2 キー、`:wq` は 4 キー。`ZZ` を使う
- **`:q!` vs `ZQ`**: 同義。`ZQ` は 2 キー。破棄するなら `ZQ`
- **`gf` vs `:e %:h/{file}`**: `gf` は `'path'` で自動解決。`'path'=.,**` で再帰検索。`import 'foo'` 風参照に有用
- **`:e .` vs ファイルプラグイン**: 内蔵 netrw はプラグイン無しで動く。`nerdtree`、`nvim-tree`、`oil.nvim` の方が良いがセットアップ要

## 実例

```text
直前のファイルを開く:           :e #
ディスクから再読込:             :e!
バックアップ保存:               :w %.bak
現ファイルをリネーム:           :saveas newname.txt
カーソル下のファイルを開く:     gf
ヘッダーファイルへ:             :exe 'e' expand('%:r').'.h'    （foo.c → foo.h。`%:r.h` は cmdline parser の解釈が曖昧なため `:exe` + `expand()` で確実に連結する）
現ディレクトリへのパス:         :e %:h/
部分名で検索:                   :find foo*
```

## Web 環境について

本サイトのドリル（CodeMirror ベース）には**ファイルシステムが無い**。`:e` `:w` 等は動作しない。本記事はドリル卒業後の実 Vim 使用を見据えたマスター知識。

## 落とし穴

- 引数なしの `:w` は**現バッファ名**で保存。別ファイルに保存するなら `:w other.txt`。`:saveas` と混同しない
- 読み取り専用フラグのファイルに `:wq` は拒否される。`:wq!` または `:w !sudo tee %` で回避
- `gf` はファイル存在前提。カーソル下の非存在ファイルを作るなら `:e <cfile>` の後 `:w`
- `:!` 内の `%` は**エスケープされない** — 空白を含むファイル名で壊れる。`:!cmd "%"` または `expand('%:S')`
- 変更未保存で終了すると undo file が無い限り作業は失われる
