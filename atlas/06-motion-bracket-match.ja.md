# 括弧マッチ

対の括弧へジャンプ・囲んでいるブロックを移動する。ネストされたコードをスクロールなしで読む鍵。

## コマンド一覧

| Key    | 動作                                                              |
|--------|-------------------------------------------------------------------|
| `%`    | 対応する `()` `[]` `{}` へジャンプ（カーソル位置から行内を右方向に走査して最初に見つかった括弧の対へ — カーソルが括弧の真上にある必要はない） |
| `[(`   | 後方の**未対応**の `(` へ                                          |
| `])`   | 前方の**未対応**の `)` へ                                          |
| `[{`   | 後方の**未対応**の `{` へ                                          |
| `]}`   | 前方の**未対応**の `}` へ                                          |
| `[/`   | 後方の C コメント開始へ                                            |
| `]/`   | 前方の C コメント終了へ                                            |
| `[#`   | 後方の未対応 `#if` / `#else` へ                                    |
| `]#`   | 前方の未対応 `#else` / `#endif` へ                                 |

## 使い分け

- **`%` vs `[{`/`]}`**: `%` は**現在行内**でカーソルから右へ走査して括弧を探し、その対へジャンプする（行内に括弧が必要）。`[{`/`]}` は**ブロック内のどこからでも**動く — 囲んでいる括弧へジャンプ。現在行に括弧が無い時は `[{`
- **`%` vs text object**: `%` はカーソル移動、`vi{` `ci{` は中身に対する操作。移動は `%`、編集には text object
- **`%` vs `:set matchpairs+=<:>`**: デフォルトは `()` `[]` `{}` + `'matchpairs'` のみマッチ。`<:>` を追加すると HTML/XML タグもマッチ。`matchit` プラグイン（**Neovim: 既定有効**、Vim: 同梱だが `:packadd matchit` 要）で `%` を `if`/`endif`、`def`/`end`、HTML タグまで拡張可能。詳細は Pitfalls 参照
- **`]}` vs `}`**: `]}` は**囲んでいる**ブロックの閉じカッコへ。`}` は次の空白行へ。まったく別概念

## 文法での位置づけ

括弧 motion は operator と合成可:

- `d%`   — `(` から対応 `)` まで削除（括弧式）
- `y%`   — 括弧グループ全体をヤンク
- `c%`   — 括弧式を置換
- `v%`   — 括弧から括弧まで visual 選択
- `d]}`  — カーソルから囲みブロック末尾まで削除

## 実例

```text
if (cond|ition && other) {       %  → ( の上で → 対応の ) へ
function long_one() {            [{ → 内部から、開き { へ
  ...                            ]} → 内部から、閉じ } へ
  cursor here|
  ...
}

引数リスト削除:        di(   （text object 形式、% 不要）
関数本体を選択:        vi{
囲みブロックを整形:    =i{
```

## 落とし穴

- `%` は文字列・コメント内の括弧を syntax 依存では区別しない。挙動は `'cpoptions'` の `%` フラグと matchit に依存
- **`%` と `{n}%` は別コマンド**: count なしの `%` は括弧マッチ、count 付き `{n}%` は**ファイルの n パーセント位置へ**ジャンプ（`50%` で中央）。`5%` は「5 番目の括弧ペア」の意ではない。混同しない
- `%` はデフォルトでは山括弧 `<>` をマッチしない — HTML/JSX 編集には `:set matchpairs+=<:>`
- `matchit` プラグインで `%` を大幅拡張可能（HTML タグ、`if`/`endif` 等）。**Neovim は 0.5 以降デフォルトで有効**（無効化したいなら `let loaded_matchit = 1`）。Vim は同梱だが未ロードなので `~/.vimrc` に `:packadd matchit` を追加
- `[{` は**囲み**の `{` を探す。ネストに関係なく直前の `{` ではない。`]}` と対
