# Vim 正規表現 — パターンと置換

Vim には独自の regex 方言がある。**PCRE ではない**。最大の罠は **magic モード** — Vim 既定のエスケープ規則は他言語経験者全員を混乱させる。

## Magic モード

| モード | 切替 | 効果                                                       |
|--------|------|------------------------------------------------------------|
| Very magic   | `\v...` | regex メタ文字が**エスケープ不要**（PCRE に最も近い） |
| Magic（既定）| ―       | `()` `{}` `+` はバックスラッシュ必要、`*` `.` `[]` `^` `$` は不要 |
| Nomagic      | `\M...` | ほとんどのメタ文字にバックスラッシュ必要                |
| Very nomagic | `\V...` | `\` だけ特殊、他はすべてリテラル                        |

**推奨**: 複雑なパターンは常に `\v` を前置。`\v` が「他言語と同じ感覚」。

## パターン要素

**バックスラッシュ付き要素**（`\d` `\w` `\s` `\zs` `\<` 等）はどの magic モードでも同じ書式で動く — バックスラッシュは原子の一部。素のメタ文字は `\V`（very nomagic）下で挙動が変わる: `.` と `[]` はリテラル化、`^` と `$` はパターン先頭/末尾でのみアンカーとして機能（それ以外の位置ではリテラル）。予測可能性なら `\v` を使う。

| 要素              | 意味                                                  |
|-------------------|-------------------------------------------------------|
| `.`               | 任意の文字                                            |
| `^`               | 行頭                                                   |
| `$`               | 行末                                                   |
| `\<`              | 単語境界（開始）                                       |
| `\>`              | 単語境界（終了）                                       |
| `\zs`             | マッチ開始（前は要求するが捕獲しない）                 |
| `\ze`             | マッチ終了                                             |
| `\d` `\D`         | 数字 / 非数字                                          |
| `\w` `\W`         | 単語文字 / 非単語文字                                  |
| `\s` `\S`         | 空白 / 非空白                                          |
| `\a` `\A`         | アルファベット / 非アルファ                            |
| `\u` `\U`         | 大文字 / 非大文字                                      |
| `\l` `\L`         | 小文字 / 非小文字                                      |
| `[abc]`           | 文字クラス                                             |
| `[^abc]`          | 否定クラス                                             |
| `[[:alpha:]]`     | POSIX クラス                                           |

## 量化子

| 要素（very magic）| Magic 等価 | 意味                |
|-------------------|------------|---------------------|
| `*`               | `*`        | 0 回以上（貪欲）    |
| `+`               | `\+`       | 1 回以上            |
| `?`               | `\=`       | 0 または 1          |
| `{n,m}`           | `\{n,m}`   | n〜m 回             |
| `{-}`             | `\{-}`     | 非貪欲（lazy）       |

## グループと交替

| パターン（very magic）| 意味                                                |
|----------------------|----------------------------------------------------|
| `(...)`              | 捕獲グループ（magic では `\(...\)`）                |
| `\1` 〜 `\9`         | 後方参照                                            |
| `\%(...\)` / `%(...)`（`\v`） | 非捕獲グループ。`\v` 下では `%(...)` のようにバックスラッシュ無しでも書ける（`\%(...\)` も動作する） |
| `\|` (magic) / `|` (very magic) | 交替: `\v` 下は `(a|b)`、デフォルト magic では `\(a\|b\)` |

## 置換側の特殊（`:s/pat/REP/` 内）

| トークン     | 意味                                                          |
|--------------|---------------------------------------------------------------|
| `&`          | マッチ全体                                                    |
| `\0`         | `&` と同義                                                    |
| `\1` 〜 `\9` | 捕獲グループ                                                  |
| `\u`         | 次の 1 文字を大文字化                                          |
| `\l`         | 次の 1 文字を小文字化                                          |
| `\U`         | ここから `\E` まで大文字化                                     |
| `\L`         | ここから `\E` まで小文字化                                     |
| `\E`         | 大小変換の終了                                                 |
| `\r`         | 改行                                                           |
| `\t`         | タブ                                                           |
| `\=expr`     | `expr`（Vim 式）の評価結果で置換                              |

## 使い分け

- **`\v` vs 既定 magic**: `(`、`+`、`{`、`?`、`|` を含むパターンは常に `\v` を前置。バックスラッシュ地獄を避けられる
- **`*`（貪欲）vs `{-}`（lazy）**: `a.*b` は最長一致、`a.\{-}b` は最短一致。HTML 属性・JSON 値など構造化コンテンツを切り出す時は lazy
- **`\zs`/`\ze` vs グループ**: 両者とも文脈マッチに使える。**捕獲なしでアンカーだけ**したいなら `\zs`/`\ze` が単純: `/href=\zs[^"]\+\ze"` で URL だけ選択
- **`&` vs `\0`**: 置換で同義。短い `&` を使う
- **`\=expr` vs sed 風**: `\=` はマッチごとに Vim script を実行。`\=submatch(0)+1` でマッチした数字を加算。PCRE/sed には無い Vim の超能力

## 実例

```text
各単語をクォートで囲む:
  :%s/\v(\w+)/"\1"/g

見出しを小文字化:
  :%s/\v^#+\s+\zs.+/\L&/

全行に行番号付加:
  :%s/\v^/\=line('.').' '/

2 列を入れ替え（CSV）:
  :%s/\v^([^,]+),([^,]+)$/\2,\1/

数値を全部 +1:
  :%s/\v\d+/\=submatch(0)+1/g

href 内容にマッチ:
  /\vhref\="\zs[^"]+\ze"
```

## 落とし穴

- 既定の magic では `()` は**リテラル括弧**。捕獲には `\(...\)` 必要。`\v` で回避
- `\<` `\>` は単語境界であって**不等号ではない**。リテラル `<` `>` をマッチしたいなら `[<]` `[>]`（`\v` 下なら `<` を直接書ける）
- 大小区別は `ignorecase` / `smartcase` **と** `\c` / `\C` 上書きの相互作用。混乱しやすい — `\C` は設定を無視して強制大小区別
- `:s` の `pat` を空にすると**最後の検索パターン**を使う: `/foo<CR>` 後の `:s//bar/g` は foo を置換
- `\n` は**検索**で改行マッチだが**置換**ではヌルバイト。置換で改行を入れたいなら `\r`
