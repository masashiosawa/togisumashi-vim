# Substitute — Search and Replace

`:s` ex コマンドで正規表現置換。range とフラグの組合せで「テキスト書換」のほぼ全用途をカバーする。

## コマンド一覧

| 形式                            | 効果                                                            |
|---------------------------------|-----------------------------------------------------------------|
| `:s/{pat}/{rep}/`               | 現在行の最初のマッチを置換                                     |
| `:s/{pat}/{rep}/g`              | 現在行の全マッチ                                                |
| `:%s/{pat}/{rep}/g`             | ファイル全体（`%` = 全行）                                      |
| `:%s/{pat}/{rep}/gc`            | 確認プロンプト付きで全マッチ                                    |
| `:[range]s/{pat}/{rep}/`        | range 内で置換                                                  |
| `:'<,'>s/{pat}/{rep}/g`         | visual 選択内で                                                 |
| `:g/{pat}/s//{rep}/g`           | `{pat}` にマッチする行で substitute（`//` で同パターン再利用） |
| `&`                             | Normal モードで直前の `:s` を現在行で繰返し（**フラグは破棄される**） |
| `:&&`                           | 直前の `:s` を現在行で繰返し（**フラグを保持**）                 |
| `g&`                            | 直前の `:s` をファイル全体で繰返し（パターン・置換・フラグ全て保持） |
| `:s//{rep}/g`                   | 空 `{pat}` で**最後の検索パターン**を再利用                     |

## フラグ

| フラグ | 効果                                                            |
|--------|-----------------------------------------------------------------|
| `g`    | 各行の全マッチ（デフォルト: 最初のみ）                          |
| `c`    | 各置換で確認                                                    |
| `i`    | このマッチで大小区別なし                                        |
| `I`    | 大小区別あり（`ignorecase` をオーバライド）                     |
| `n`    | 置換せずマッチ数のみ                                            |
| `e`    | マッチなしでもエラーにしない                                    |
| `&`    | 前回の `:s` のフラグを再利用（**フラグ列の先頭に書く必要あり**） |

## 置換側の特殊

| トークン     | 意味                                                              |
|--------------|-------------------------------------------------------------------|
| `&` または `\0` | マッチ全体                                                     |
| `\1`..`\9`   | 捕獲グループ                                                      |
| `\u` `\l`    | 次の 1 文字を大/小文字化                                          |
| `\U` `\L`    | `\E` まで大/小文字化                                              |
| `\E`         | 大小変換終了                                                      |
| `\r`         | 改行（置換内）                                                    |
| `\=expr`     | Vim 式 `expr` の評価結果で置換                                    |
| `~`          | 前回の置換文字列を再利用（magic 非依存。リテラル `~` は `\~`）    |

## 使い分け

- **`:s` vs `cgn`**: `:s` は一括 — 速くて最終的。`cgn` は 1 マッチずつ対話的に変更して `.` で進む。信頼できるパターンなら `:s`、目で見たいなら `cgn`
- **`:s` vs `:g/.../s//.../g`**: `:%s/foo/bar/g` は全箇所、`:g/^if/s/foo/bar/g` は **`if` で始まる行だけ**置換 — 行単位の条件制御
- **`:s` vs LSP rename**: LSP rename はシンボル認識（スコープ・ファイル境界）、`:s` はテキスト。リファクタリングは LSP、テキスト書換は `:s`
- **Range `%` vs `1,$`**: 同義。`%` の方が短い
- **確認 `c` vs `c` なし**: `c` で各マッチに `y/n/a/q/l` プロンプト。不安なパターンや初回は `c`、確信があれば外す
- **`&` vs `:&&` vs `g&`**: Normal モードの `&` は直前の `:s` を現在行で繰返すが**フラグは破棄**される（`:%s/foo/bar/g` 後の `&` は `g` が外れて各行最初のマッチのみ置換 — よく嵌まる）。フラグを保ちたいなら `:&&`。`g&` はファイル全体でパターン/置換/フラグ全て保持して再実行

## 実例

```text
変数名を全置換:
  :%s/\<oldName\>/newName/g

確認付きリネーム:
  :%s/\<old\>/new/gc

visual 範囲内で:
  Vap → :'<,'>s/foo/bar/g

全数値を +1:
  :%s/\v\d+/\=submatch(0)+1/g

各単語をクォートで囲む:
  :%s/\v(\w+)/"\1"/g

文頭を大文字化:
  :%s/\v(^|\.\s+)([a-z])/\1\u\2/g

CSV 最後の 2 列を入替:
  :%s/\v^(.*),([^,]+),([^,]+)$/\1,\3,\2/

マッチ数を数える:
  :%s/pattern//n
```

## 落とし穴

- デフォルト `:s` は**各行最初のマッチのみ**。全マッチには `g` を付ける。誰もが 1 度は引っかかる
- 区切り文字は 2 文字目 — パターンに `/` を含むなら `:s#foo#bar#g`
- `\n` と `\r` は検索側と置換側で**意味が逆転**する。**検索**側の `\n` は改行マッチ、**置換**側の `\n` は **NUL バイト (0x00)** を挿入する（Vim の内部行区切り、ファイル中では `^@` と表示）— **行は分割しない**。置換側の `\r` こそが実改行を入れる。**初心者は必ず逆に覚える** — 置換で改行を入れたいなら `\r`
- 大小区別は `ignorecase` と `smartcase` に従う。パターン内 `\C`（区別あり）`\c`（なし）で上書き可能
- `:s` をパターン空（`:s//bar/g`）で実行すると**最後の検索**を再利用 — 直前に検索したことを忘れていると混乱する
- Neovim には `'inccommand'`（`split`/`nosplit`）で `:s` のライブプレビューがある — `<CR>` 前に結果を確認できて便利。Vim には組込なし。（`'incsearch'` は `/` 検索のプレビューで、`:s` には効かない — 混同しない）
