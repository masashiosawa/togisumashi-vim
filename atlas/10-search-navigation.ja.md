# パターン検索と移動

パターンマッチでバッファを移動する。最強の motion 群 — 検索はジャンプであり、operator の対象でもある。

## コマンド一覧

| Key            | 動作                                                            |
|----------------|-----------------------------------------------------------------|
| `/{pat}<CR>`   | `{pat}` を前方検索                                              |
| `?{pat}<CR>`   | 後方検索                                                        |
| `/<CR>`        | 空パターンで最後の検索を前方繰返し（直前が `/` なら `n` と同等）  |
| `?<CR>`        | 空パターンで最後の検索を後方繰返し                              |
| `n`            | 次のマッチ（元検索と同方向）                                    |
| `N`            | 前のマッチ（逆方向）                                            |
| `*`            | カーソル下の**単語**を前方検索（whole word）                    |
| `#`            | カーソル下の単語を後方検索                                      |
| `g*`           | `*` 同様、ただし**部分マッチ**（`\<\>` アンカーなし）            |
| `g#`           | `#` の部分マッチ版                                              |
| `gd`           | **現在関数内の最初の宣言**へ（regex ヒューリスティック、無ければ 1 行目から） |
| `gD`           | **ファイル全体の最初の出現**へ（1 行目から）                    |
| `gn`           | 次のマッチを visual 選択（operator 対応）                       |
| `gN`           | 前のマッチを visual 選択                                        |

## 使い分け

- **`/` vs `f`**: `/` はパターン・複数行・正規表現可・`<CR>` 必要。`f` は単文字・現在行のみ・`<CR>` 不要。行内の見える 1 文字なら `f` の方が速い
- **`*` vs `/word`**: `*` は「カーソル下を検索」— 入力不要。`/word` は入力が要る。カーソルが既に対象上なら `*`
- **`*` vs `g*`**: `*` は `\<word\>` アンカー付き（whole word）、`g*` はアンカーなし（部分マッチ）。`foobar` の中の `foo` を含めたいなら `g*`
- **`gd` vs `<C-]>`（tags）**: `gd` はファイル**内**の定義探索（tags 不要）、`<C-]>` はタグ経由（ファイル横断）。ローカル変数は `gd`、プロジェクト横断シンボルは `<C-]>`
- **`cgn` vs `:s/.../.../g`**: 両者ともパターン置換。`cgn` は対話的に変更して `.` で繰返し — 1 件ずつ確認。`:s/.../g` は一括。確認したいなら `cgn`、信頼できるパターンなら `:s`
- **`n` vs `;`**: `n` は `/`/`?` の繰返し、`;` は `f`/`t` の繰返し。履歴は独立

## 検索編集ループ（最頻 Vim パターン）

```text
/foo<CR>      最初の foo を検索
cw bar<Esc>   bar に置換
n             次の foo
.             変更を繰返し
n             次の foo
.             ...
```

`cgn` 併用版:

```text
/foo<CR>
cgn bar<Esc>     次マッチを bar に置換
.                次マッチ + 置換
.                ...
```

## 検索修飾子

### 接尾フラグ（閉じ `/` の後）

| 形式        | 意味                                                       |
|-------------|------------------------------------------------------------|
| `/{pat}/e`  | カーソルをマッチの**末尾**に                               |
| `/{pat}/s+1`| マッチ開始 `+1` 位置に                                     |

### パターン内大小区別フラグ（パターンのどこに書いても可）

| 形式     | 意味                                                          |
|----------|---------------------------------------------------------------|
| `\c`     | このパターンを強制大小区別なし（`'ignorecase'` をオーバライド） |
| `\C`     | このパターンを強制大小区別あり                                |

## 実例

```text
クラス検索:           /class Foo<CR>
編集として繰返し:     cwBar<Esc>n.
カーソル下を検索:     *  →  *  →  *   （全出現を巡回）
定義参照:             変数の上で  →  gd
次マッチを visual:    /TODO<CR>  →  gn   （TODO が選択される）
ファイル全置換:       /TODO<CR>  →  cgn done<Esc>  →  .  →  .
```

## 落とし穴

- 検索履歴はセッション単位で `viminfo`/`shada` 経由で永続化。検索プロンプトで `<Up>` で呼出
- `*` は whole-word アンカー付きなので `foo` 上で `*` を打っても `foobar` には**マッチしない**。緩めたいなら `g*`
- `'incsearch'`（実時間プレビュー）と `'hlsearch'`（全マッチハイライト） — Vim raw（`-u NONE`）はどちらも off、`defaults.vim` 適用後の Vim（vimrc 不在時の事実上の既定）は `'incsearch'` **on**、`'hlsearch'` **off**。Neovim は両方 **on**。Vim で揃えるなら `:set incsearch hlsearch`
- `'wrapscan'` は Vim/Neovim とも既定 on — 検索は EOF で先頭へ折り返す（逆方向も同様）。折返したくないなら `:set nowrapscan`
- `gd` は**正規表現ヒューリスティック**（`var name` パターンを探す）。意味解析ではないので複雑コードで誤判定あり
- `n` は常に「元検索と同方向」を意味 — `?foo<CR>n` は**後方**に行く。逆転には `N`
