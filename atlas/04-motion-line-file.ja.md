# 行・ファイル単位ジャンプ

行番号や相対位置でバッファを跨いで移動する。「あれを見たい」の基本。

## コマンド一覧

| Key       | 動作                                                       |
|-----------|------------------------------------------------------------|
| `gg`      | ファイル先頭                                               |
| `G`       | ファイル末尾                                               |
| `{n}G`    | `{n}` 行目（例: `42G`）                                    |
| `{n}gg`   | `{n}G` と同じ                                              |
| `:{n}`    | `{n}G` と同じ（ex コマンド形式）                            |
| `{n}%`    | ファイルの `{n}` パーセント位置                            |
| `+`       | 次行の最初の非空白                                         |
| `-`       | 前行の最初の非空白                                         |
| `{n}_`    | `[count]-1` 行下の最初の非空白（`_` は現在行、`3_` で 2 行下） |

## 使い分け

- **`gg`/`G` vs `:1`/`:$`**: 結果は同じ。`gg`/`G` の方が速い（`<CR>` 不要）。`:1,42d` のような range 構築時は ex 形式を使う
- **`{n}G` vs `:{n}`**: 同じ行へ到達。キーボード流なら `{n}G`、コンパイラ/linter メッセージから貼り付けるなら `:{n}`
- **`{n}G` vs `{n}%`**: `{n}G` は文字通り `{n}` 行目、`{n}%` はファイルの何パーセントか（`50%` は中央）。行数不明だが「だいたい真ん中」に行きたい時は `%`
- **`+`/`-` vs `j^`/`k^`**: `+` は `j^` と完全等価（次行の最初の非空白）。1 打少なくて済むのでインデントコード内で活躍
- **`{n}G` vs `m{a}` + `'{a}`**: 番号が分かっているなら `{n}G`、戻りたい場所には mark — 番号を覚える必要が無い

## 文法での位置づけ

行ジャンプも motion なので operator と合成可:

- `dG`   — カーソルからファイル末尾まで削除
- `d{n}G` — カーソルから `n` 行目まで削除
- `yG`   — ファイル末尾までヤンク
- `ggdG` — ファイル全削除

## 実例

```text
ファイルを行 42 で開く:           vim file +42    or    :42 / 42G
10〜20 行を削除:                  :10,20d
末尾までヤンク:                   y G
巨大ファイルの真ん中:             50%
飛んでから戻る:                   G  （その後）  ''  で元の位置へ
```

## 落とし穴

- `gg` `G` はデフォルトで**最初の非空白**に着地。列 0 が欲しい時は `gg0`/`G0` か `:set nostartofline`
- `{n}%` は**パーセント**であって行番号ではない — `100%` は最終行、行 100 ではない。count は **1〜100** が有効範囲、範囲外は受け付けられない。行 100 へは `100G`
- count 無しの `G` で最終行。motion としての「0 行目」は存在しないが、`:0` は ex で 0 アンカーとして機能（`:0r file` でファイルを 1 行目の**前**に読み込む等）
